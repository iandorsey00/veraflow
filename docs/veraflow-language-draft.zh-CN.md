# VeraFlow 模板语言与输出区段

[English](veraflow-language-draft.md) · 简体中文

## 普通模板

使用 UTF-8 保存 `.veraflow` 或 `.vf` 文件。简单模板不需要文件头，默认输出为一个正文区段。

```text
你好，{{姓名}}！你的订单号是 {{订单号}}。
```

字段名区分大小写。占位符两端的空白会被忽略，名称内部的空格有意义。相同字段多次出现时使用同一个值。缺少必填值时不能准备输出，明确提供的空字符串会输出为空。替换只执行一遍，字段值中的 `{{其他字段}}` 会原样保留。正文中用 `\{{` 输出字面的左双花括号。用 `\\` 输出一个反斜杠。

## 高级模板

文件第一行使用 `--- veraflow 2`，接着写一个 JSON 对象，再用单独一行 `---` 结束文件头。头部支持 LF 或 CRLF。数字 2 标识源文件语法，与应用版本和旧版 JSON 归档版本分别演进。JSON 属性和字符串仍用双引号。

```text
--- veraflow 2
{
  "title": "订单通知",
  "workflow": "form",
  "fields": {
    "Name": {"type": "text", "label": "客户姓名", "optional": true},
    "review": {"type": "boolean", "label": "需要复核", "default": false}
  }
}
---
您好{{when Name is not blank:
  '，{{Name}}'
}}。您的订单已准备好。
```

`title` 用于会话标题和最近打开列表，最多 250 个字符，限一行。`workflow` 可为 `"form"`（填写表单）、`"scanner"`（扫描器）`"csv"`（关联 CSV）或 `"append"`（追加行）。省略时，打开文件会提示选择。表单和扫描器之间切换时会保留已填写的值。未声明的占位符会推断为文本字段。

### 字段与选项

| 属性              | 用法                                                                              |
| ----------------- | --------------------------------------------------------------------------------- |
| `type`            | `boolean`、`text`、`textarea`、`email`、`date`、`number`、`radio` 或 `dropdown`   |
| `label`           | 界面上显示的名称，可用中文。占位符、条件和 CSV 表头仍用字段 ID                    |
| `multiline`       | 适用于文本。`text` 默认单行，`textarea` 默认多行                                  |
| `allowBlankLines` | 多行文本默认允许空白行。设为 `false` 时自动去掉空行和只含空白的行                 |
| `optional`        | 可选字段未提供值时输出为空                                                        |
| `default`         | 布尔字段用 JSON 的 `true` 或 `false`。其他类型用字符串。选择字段的默认值是选项 ID |
| `options`         | 用于 `radio` 和 `dropdown`。每个选项包含唯一的 `id`、`label`，可另设 `output`     |

字段名区分大小写，可包含空格、中文和标点。如果名称中的花括号等字符可能被解析成语法，请用 JSON 双引号包裹，例如 `{{"地点 {编号}"}}`。条件也接受带双引号的字段名。布尔字段没有隐含默认值，CSV 中用字符串 `true` 或 `false`。未设置默认值的选择字段采用第一个选项。直接输出选择字段时使用该选项的 `output`，缺省时使用 `label`。

表单先显示选项，再显示文本字段。同一组中，控制条件的字段优先。扫描器中直接选择选项并应用，较短的列表显示为单选按钮。如需核对，再选择一次进行比较。

### 行内条件和条件块

行内条件只输出所选字符串。条件中的 `else` 可省略。字符串可用半角单引号或双引号，可包含普通占位符。引号外的换行只用于排版。想在输出中换行，请在引号内写 `\n`。

```text
{{when review: '"Joe Sample" <joe.sample@example.com>'
  else: 'dispatch@example.com'}}
```

条件可写布尔字段名、`route=review`（与选项 ID 比较）、`Name is blank` 或 `Name is not blank`。空值判断涵盖缺失、空字符串和仅含空白的值。字符串使用 JSON 转义，单引号内还可用 `\'`。如需在引号内显示字面占位符，写 `\\{{字段}}`。只有选中的分支需要其中的字段值。

多行输出可用条件块。每个标签单独占一行。标签行本身不会输出，所选分支中的换行会保留。

```text
{{#when attn is not blank}}
收件人：{{attn}}
{{/when}}
```

### 输出区段与粘贴导航

用 `{{#section body '正文'}}` 和 `{{/section}}` 划分区段。标签各占一行，每个区段 ID 必须唯一，区段之间只能有空白。使用区段后，所有输出都应写在区段内。区段按源文件顺序输出。结束标签前的一次换行是结构的一部分。如需保留结尾换行，在结束标签前加一个空行。

在 **粘贴选项** 中可 **调整区段顺序…**。调整后从第一个区段开始，每次快捷键只粘贴一个区段，不发送导航按键。**恢复模板顺序** 同时恢复先前的粘贴设置。调整顺序不会改写模板、文本导出或历史记录。

可选的文件头配置：

```json
{
  "delivery": {
    "mode": "step",
    "after": { "recipient": ["Tab", "Tab"], "subject": ["Tab"] },
    "separator": "\n\n"
  }
}
```

- `mode` 默认 `"step"`，每次快捷键粘贴一个区段。`"sequence"` 一次粘贴当前位置之后的全部区段。
- `after` 将区段 ID 对应到按键列表，最多 16 项，只允许 `"Tab"` 和 `"Shift+Tab"`。空列表表示不执行导航。最后一个区段不发送导航按键。未指定时可用 **模板未指定按键时按 Tab**。
- **合并粘贴区段** 会把各区段拼成一个文本块。`separator` 默认是一个换行，仅用于合并输出。设为 `"\n\n"` 可插入一个空行。

先点击 **准备输出区段**，再把光标放在目标应用中的正确位置，并按窗口显示的快捷键。如果粘贴中途失败，先检查目标应用，再重试或使用 **复制当前区段**。

## 注释、循环和内置变量

高级模板正文用 `{{! 这里只给模板作者看 }}` 添加注释。注释不出现在输出里。独占一行的注释连同行末换行一起去掉。文件头仍使用标准 JSON。

文本条件可用 `{{when Route equals "Express": '优先'}}` 做完整匹配，或用 `{{when Address contains 'Suite': '检查门禁'}}` 判断是否包含某段文字。比较区分大小写并使用原始值。未提供的值不匹配。块语法和 `else if` 也支持这些条件。

```text
{{#for task in ["检查标签", "确认目的地"]}}
- {{task}}
{{/for}}
{{#for n in range(1, 4)}}
副本 {{n}}
{{/for}}
```

循环标签各自独占一行。列表遵循 JSON 语法，支持字符串、数字和布尔值。范围不包含结束值，`range(7)` 表示 0 至 6。循环变量只在循环体中有效，不会创建输入字段。每个循环最多 100 项。

用 `{{@date "%Y-%m-%d"}}` 输出日期，用 `{{@timestamp}}` 输出 ISO 8601 时间戳。同一次会话使用固定的 UTC 时间。格式支持 `%Y`、`%m`、`%d`、`%H`、`%M`、`%S` 和 `%%`。另可用 `{{@template}}` 及 `{{@output}}` 输出名称。在关联 CSV 模式中，`{{@row}}` 是从 1 开始的数据行号，`{{@rows}}` 是数据行总数，`{{@csv_file}}` 是相对路径。内置变量也可用于文件名及 CSV 行标签。可参考[派送单示例](../examples/source/dispatch-note.veraflow)。

## 保存、恢复和 CSV

从输出关闭会话时，可 **返回表单** 或 **返回扫描器**。**保存预填模板** 会保存模板、响应和核对状态，稍后仍可继续编辑。默认文件名包含模板标题和 UTC 时间戳。输出完整且通过所需核对时可以 **将输出保存为文本**。从旧版模板库导出可共享的模板定义时，不带预填响应。

预填文件头使用 `responses` 对象。响应为字符串，布尔值为 `"true"` 或 `"false"`。省略键会使用字段默认值，`null` 表示未回答且不使用默认值，`""` 表示明确留空。普通文本模板保存成预填文件时使用 `"syntax": "plain"`。可选的 `verification` 对象以字段名为键，值为 `"form"` 或 `"scanner"`。已核对字段必须有非空响应。使用原工作流程打开时会恢复核对状态，修改字段后会清除该状态，也可随时重新核对。请打开来源可信的预填文件。

**最近的输出** 默认保留 5 条已准备的源模板结果，仅供复制和导出。可在设置中将数量设为 0–20，设为 0 会关闭并清空历史。预填文件和本地输出历史均以明文保存。

打开带表头的 UTF-8 CSV 后，可搜索或按行号选择一条记录，预览后用 **自由扫描器** 打开，或选择模板填充。列名与模板字段 ID 必须完全匹配。可用[示例文件](../examples/source/README.zh-CN.md)试用。

### 关联 CSV

在模板文件头中加入以下属性，即可直接打开输出页面。CSV 应位于模板所在文件夹或其子文件夹中。各平台都用 `/` 分隔路径。

```json
{
  "workflow": "csv",
  "csv": {
    "file": "data/visits.csv",
    "rowLabel": "{{编号}} · {{联系人}}"
  }
}
```

CSV 使用 UTF-8，表头不能为空或重复，表头与字段名精确匹配，包括大小写和空格。空单元格传入空字符串。字段缺少对应列时，使用模板指定的默认值。可选的 `rowLabel` 可以用 CSV 列占位符格式化每一行。每个标签都以行号开头，省略 `rowLabel` 时，软件会显示前几个单元格的摘要。CSV 大小上限为 64 MiB，最多可包含 100,000 条数据行。大型文件的行下拉框每页显示 500 行。

**行**下拉框在**输出**下拉框上方。行箭头依次浏览当前输出的所有行，到末行时继续到下一输出的首行，也可反向浏览。输出箭头切换输出并保留当前行。用 Tab 聚焦下拉框或箭头按钮，再用下拉框自己的键盘操作，或按 Enter 或空格触发箭头。表单和扫描器有多个输出时也会显示输出箭头。可试用[关联模板](../examples/source/linked-records.veraflow)和[配套 CSV](../examples/source/linked-records.csv)。

## 一条记录生成多个输出

用单独一行的 `{{#output id "名称"}}` 和 `{{/output}}` 包围各个输出。每个输出 ID 必须唯一。块内可写普通文本，也可使用独立的 `section` 区段。字段在文件头中只定义一次。即使没有任何输出引用，字段仍可存入记录。

在表单或扫描器中选择输出，即可预览并准备该输出。切换时会保留已填字段。需要同时复制多个区段时，可选择 **复制完整输出**。也可以在输出页面直接切换。切换后从第一个区段开始。若新输出有未填写或未核对的字段，VeraFlow 会保留当前输出并显示错误。正文中用实际的 Tab 字符分隔字段，即可将一行粘贴到电子表格。若目标应用将换行视作新行，请使用单行字段。参见[共享记录示例](../examples/source/shared-record.veraflow)。

可选的 `"outputs"` 对象按输出 ID 设置粘贴规则。每项在 `"delivery"` 对象中设置粘贴规则，例如 `"outputs": {"email": {"delivery": {"mode": "sequence"}}}`。省略的属性继承顶层设置。指定 `after` 时会替换默认导航配置。区段 ID 和导航只在对应输出内生效。

**将记录保存为 JSON…** 将字段 ID 与原始值存为对象。未填写字段为 `null`。**保存预填模板** 会同时保存模板和响应，以便重新打开。文件头可用 `"filename"` 设置建议文件名。支持 `{{timestamp}}`、`{{template_name}}`、`{{workflow_name}}`、`{{output_name}}` 和 `{{field.Reference}}`。未回答字段不会插入字符。应用会清理文件名并添加扩展名，是否替换已有文件由系统的保存对话框确认。

## 条件分支与来源证据

`not ready` 用于判断布尔字段是否明确为假。未填写的布尔字段仍待确定。可在最终的 `else` 之前用 `else if` 依次判断。条件块中的 `{{else if review}}` 单独占一行。行内示例为 `{{when not ready: '暂缓' else if review: '复核' else: '就绪'}}`。

在表单或扫描器中选择 **比较来源文本…**，然后粘贴原文。比较可按字段 ID 或标签匹配 `Reference: VF-104` 之类的行。没有对应标签时，整行一致只能作为较弱的线索。应用会分别报告多个候选值、冲突和缺失。批量比较不会改变字段的核对状态。需确认时可逐字段核对。请求粘贴也不代表传输准确或目标应用已完成操作。

## 追加行

在表单、扫描器或 CSV 浏览页选择 **追加行**。写入前，检查目标 CSV 路径、列名和单元格内容。目标文件须使用 UTF-8，且表头唯一。只有表头的 CSV 也可以追加首行。目标文件被占用或发生变化时，应用会保留记录。选择 **更换或重新加载 CSV…** 后再核对并重试。共享 CSV 建议一次只由一个程序写入。

模板文件头可以使用 `append.file` 指定同一目录或子目录中的 CSV，使用 `append.duplicateKey` 指定查重列，使用 `append.carryForward` 指定开始下一条记录时保留的字段。查重按精确值进行。发现重复时可以查看原记录，再决定是否继续。追加成功后会显示文件名和数据行号。

用 `outputs.<id>.row` 将 CSV 表头映射到单元格模板，隐式输出的 ID 为 `main`。省略映射时按字段名匹配。单元格支持占位符、条件、变量和循环。循环只生成单元格文本。**复制为电子表格行** 可以将一行复制到剪贴板，然后粘贴到 Excel。

表单、扫描器和追加行共享当前记录。浏览 CSV 时保留草稿并记住当前行。选择 **在表单中使用此行** 可编辑当前行，替换已有草稿前会确认。CSV 导入的数据需要重新核对。
