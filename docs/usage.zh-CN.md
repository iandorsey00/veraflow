# VeraFlow Web 使用指南

[English](usage.md) · [示例](../examples/README.zh-CN.md) · [桌面端 CLI 与 Web 教程](desktop-cli.zh-CN.md)

**来源 → 工作记录 → 命名输出 → 目标位置**

工作记录是表单在各步骤中维护的一组字段值。稳定的字段 ID 将这些值与各项命名输出关联起来。严格 JSON 可在工具之间传递工作记录。生成的文本可复制或下载，用于邮件、工单或日志。

选择“打开采集请求…”可将桌面端发出的采集请求导出为独立的离线 HTML 问卷。填写者可下载兼容的回答 JSON。[离线采集教程](collection.zh-CN.md)

## 各界面支持的输入

| 输入 | Web 导出页面 | 导出的独立 HTML 表单 |
| --- | --- | --- |
| `.veraflow` 或 `.vf` 模板 | 打开模板并导出。模板头的元数据可以使用 JSON5。 | 导出时嵌入模板，编辑时使用原模板文件。 |
| 扁平记录 JSON 或 JSON5 | 在“从数据开始”下选择“打开 JSON / JSON5…”。 | 在“表单工具”中打开 JSON 或 JSON5 进行审阅，或将当前回答下载为标准 JSON。 |
| 手动填写和独立核对 | 导出页面负责为填写者准备文件。 | 填写字段，并核对有此要求的字段。 |
| 带标签的文本 | 在导出的表单中提取。 | 选择“从来源提取…”，粘贴文本、打开或拖入一个 UTF-8 `.txt` 文件，或在权限允许时点击“读取剪贴板”。 |
| VeraFlow 候选值 JSON | 在导出的表单中审阅。 | 通过“从来源提取… → 外部提取文件”导入，也可从“表单工具”打开同一对话框。在审阅界面保存候选项。 |
| CSV | 选取一行并转换为扁平记录 JSON，用于预填。 | 将单行转换为候选值 JSON 供审阅，或在“表单工具”中审阅转换后的扁平记录。 |

独立 HTML 目前不支持链接 CSV、追加 CSV 和相关上下文变量，也不支持模板中的剪贴板和选中文本变量或桌面端的批量来源比对。表单支持主动读取剪贴板和独立核对字段。导出的文件可直接在浏览器中使用，无需服务器、扩展程序或相邻文件。

## 外部转换工具应输出什么格式

- **扁平记录 JSON** 适合传递一条记录中的已知值，例如 `{"serial_number":"ABC123458","quantity_affected":"1"}`。使用稳定的字段 ID 和标准选项 ID。省略字段会保留原值，`null` 清除该字段，`""` 明确表示空字符串。
- **CSV** 适合多行数据和电子表格。可使用桌面端的 CSV 工作流，或选择一行并转换后交给 Web 表单。每个独立 HTML 表单保存一条工作记录。
- **候选值 JSON** 用于传递尚待审阅的值、备选项和引文，尤其适合转换邮件或通话记录。在“外部提取文件”中导出字段说明，为转换工具提供字段 ID、标签、别名、说明及选项。字段说明不含当前回答。外部工具应使用[示例](../examples/service-email-candidates.json)所示的 VeraFlow 严格 JSON 结构。

候选值文件和字段说明使用标准 JSON。如需核对引文，请先提供原文，再导入候选值。

## 从记录开始

1. 选择“打开 JSON / JSON5…”，选择 UTF-8 编码的 `.json` 或 `.json5` 文件，或直接粘贴内容，然后点击“审阅数据”。记录须为单个扁平对象，字段 ID 不能重复，值须为标量。给 `"000184"` 这样的编号加引号可保留前导零。数字和布尔值会转为文本，十进制数字的各位会保留。请在 VeraFlow 外转换嵌套数据、HTML 结构和 XML。可将从网页复制的可见文本粘贴到表单的“从来源提取…”。
2. 可选择“生成摘要”、“编写自定义输出”（使用 `{{field}}` 占位符）或“使用表单文件”。可复用表单按字段 ID 精确匹配，显示当前值和传入值，并保留命名输出和字段规则。审阅后选择“打开已填表单”。点击“下载 HTML 表单”可保存包含本次初始回答的副本。
3. 在已打开的 HTML 表单中，使用“表单工具 → 打开 JSON / JSON5…”比较另一条记录。点击“应用已审阅的值”更新记录中包含的字段。未变更的值保留核对状态，变更的值需重新完成相应的核对。请参阅[派送演示](../examples/README.zh-CN.md#从-json-生成派送输出)。

## 填写表单

1. 手动填写或提取候选值。在“审阅候选值”中先处理待确认项，查看建议值和证据，并明确选中要应用的替换项和有歧义的候选值。与当前值一致的项默认折叠，缺少候选值的字段保留原值。
2. 在字段上方的“待处理”中，选择“跳转至下一个待处理字段”或相应链接。用独立来源核对关键值。若不一致，原填写值仍会保留。编辑字段会清除该字段的核对状态，并标记受影响的已生成或已复制输出。
3. 选择“生成输出”，或在可用时生成本步骤的全部输出。将所需段落或整项输出复制到目标位置。若剪贴板访问受阻，请用浏览器的常规复制命令复制已选中的文本，或下载文本。选择“下载输出 JSON”可保存已生成的输出。若已生成本步骤的全部输出，JSON 将包含整组输出。“下一步”需另行选择。
4. 若需保留或交回工作记录，请在关闭前使用“表单工具 → 下载回答 JSON”。在 VeraFlow Desktop 0.25.0 中打开同一模板，选择“表单工具 → 导入 JSON / JSON5…”，审阅并应用更改。每次会话分别核对字段。

若受管理的浏览器禁止打开本地 HTML 或运行 JavaScript，可咨询 IT 能否通过获批的内部 HTTPS 站点提供同一文件。邮件附件预览可能会显示页面，但不运行表单控件。
