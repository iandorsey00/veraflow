VeraFlow 核流 0.10.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Browse and search ordinary folders of `.veraflow` and `.vf` templates. Open a template in a fill-in form or Scanner, or choose a CSV row to fill it.
- Preview and paste named output sections or copy them manually. The app retains the output after a paste error.
- Save an editable prefilled template or export finished text. The old Workspace interface has been removed; upgrading retains the existing library.
- Read the [source file guide](https://github.com/iandorsey00/veraflow/blob/v0.10.0/docs/veraflow-language-draft.md) and try the [example files](https://github.com/iandorsey00/veraflow/tree/v0.10.0/examples/source).

Packages have VeraFlow updater signatures. They do not have Apple notarization or Windows publisher signing. Verify the downloaded files against `SHA256SUMS.txt`. Back up `library.json` before upgrading. To downgrade, restore a compatible backup with the app closed.
