VeraFlow 0.25.1 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Light mode uses white panes, blue controls, and clearer headings in the template library and editor.
- Forms and output screens make the current step and keyboard focus easier to see. The preview sits beside the fields in wide windows and below them in narrow windows.
- VeraFlow’s icon now matches the stroke weight and symbol height of VeraData’s. The Simplified Chinese interface displays VeraFlow 核流.

Packages have VeraFlow updater signatures. Apple notarization and Windows publisher signing are pending. Verify downloads against `SHA256SUMS.txt`.

### 简体中文

浅色模式下，模板库和编辑器采用白色面板、蓝色控件和更清晰的标题。表单和输出页面更容易辨认当前步骤和键盘焦点。窗口较宽时，预览显示在字段旁边；窗口较窄时，预览显示在字段下方。图标的线宽和图形高度与 VeraData 协调一致，简体中文界面显示「VeraFlow 核流」。

安装包具有 VeraFlow 更新签名，尚无 Apple 公证和 Windows 发布者签名。请使用 `SHA256SUMS.txt` 核对下载文件。
