VeraFlow 核流 0.23.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Open a JSON or JSON5 file from Home, or paste a record. Review the fields before opening a filled form.
- Generate a field summary, write output with placeholders, or use a form file with its own named outputs and verification rules.
- Export a working record as plain JSON and reopen it. Use **Save prefilled form** to keep the output definition and the values together.
- Includes the bilingual JSON demo, the full demo ZIP, and the VS Code extension. [English guide](https://github.com/iandorsey00/veraflow/blob/v0.23.0/README.md) · [简体中文指南](https://github.com/iandorsey00/veraflow/blob/v0.23.0/README.zh-CN.md)

Packages have VeraFlow updater signatures. Apple notarization and Windows publisher signing are pending. Verify downloads against `SHA256SUMS.txt`.

### 简体中文

在首页打开 JSON 或 JSON5 文件，或直接粘贴记录。审阅字段后，可以生成摘要、自定义输出或使用已有表单文件。可将字段值导出为标准 JSON 后重新打开；若需同时保留数据与输出定义，则可保存预填表单。发布包包含双语 JSON 演示和 VS Code 扩展。

安装包具有 VeraFlow 更新签名，尚无 Apple 公证和 Windows 发布者签名。请使用 `SHA256SUMS.txt` 核对下载文件。
