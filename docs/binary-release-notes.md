VeraFlow 核流 0.11.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Use **Paste options → Reorder sections…** when your destination has a different field order. Move sections with the keyboard or mouse. The custom order pastes one section per shortcut and sends no navigation keys.
- Reset to the template order to restore the previous paste settings. Saved text and recent output keep the order from the template.
- Read the [source file guide](https://github.com/iandorsey00/veraflow/blob/v0.11.0/docs/veraflow-language-draft.md) and try the [example files](https://github.com/iandorsey00/veraflow/tree/v0.11.0/examples/source).

Packages have VeraFlow updater signatures. They do not have Apple notarization or Windows publisher signing. Verify the downloaded files against `SHA256SUMS.txt`. Back up `library.json` before upgrading.
