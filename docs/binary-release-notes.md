VeraFlow 核流 0.9.1 is a publisher-unsigned preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- The portable standard describes UTF-8 templates, dynamic forms, ordered email output, CSV, and version 1 workspace JSON.
- The repository includes synthetic records and a standalone Python reader that renders templates outside VeraFlow. A shared fixture set checks exact output in both implementations.
- Typing and Scanner use the shared final renderer. A fresh-library export/import test checks the exact Subject, To, and Body produced by an exported template.

[Read the portable specification](https://github.com/iandorsey00/veraflow/blob/v0.9.1/docs/portable-templates.md).

Download the installer or ZIP for your platform and compare it with `SHA256SUMS.txt`. VeraFlow can also install the signed update from Settings. Back up your library before upgrading.
