VeraFlow 核流 0.19.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Enter, capture, and verify values in a single Form. **Needs attention** links to missing values and pending checks.
- Set verification for the form or for each field. Add instructions to guide someone filling it in.
- Use **Create form** for an ad hoc task or **Recently opened forms** to resume saved responses. Keep a form from a file, a custom form, and a snippet collection open together.
- Includes the VeraFlow VS Code extension. [English guide](https://github.com/iandorsey00/veraflow/blob/v0.19.0/README.md) · [简体中文指南](https://github.com/iandorsey00/veraflow/blob/v0.19.0/README.zh-CN.md)

Packages have VeraFlow updater signatures. Apple notarization and Windows publisher signing are pending. Verify downloads using `SHA256SUMS.txt`.

### 简体中文

现在可以在同一个表单中填写、采集和核对字段。通过「待处理」跳转到未填写或待核对的字段。可为整个表单设置默认核对规则，也可逐个字段指定规则。用「创建表单」临时添加字段，或从「最近打开的表单」继续填写已保存的内容。

安装包具有 VeraFlow 更新签名，尚无 Apple 公证和 Windows 发布者签名。请使用 `SHA256SUMS.txt` 核对下载文件。
