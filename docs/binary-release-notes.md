VeraFlow 核流 0.15.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Source templates support comments, text comparisons, bounded loops, formatted UTC dates, linked CSV row variables, and per-output delivery settings.
- Multiline fields with `allowBlankLines: false` remove blank lines automatically. Prefilled templates restore verification in the workflow that checked the fields.
- Available updates appear in the launcher navigation beside Settings. The included `VeraFlow_VSCode.vsix` highlights the new syntax.
- [English guide](https://github.com/iandorsey00/veraflow/blob/v0.15.0/README.md) · [简体中文指南](https://github.com/iandorsey00/veraflow/blob/v0.15.0/README.zh-CN.md)

Packages have VeraFlow updater signatures. Apple notarization and Windows publisher signing are pending. Verify downloads using `SHA256SUMS.txt`.

### 简体中文

模板支持注释、文本比较、有限循环、UTC 日期格式、关联 CSV 行变量和各输出的粘贴设置。多行字段可自动去掉空行，预填模板可恢复原工作流程的核对状态。启动页在设置旁显示可用更新，随附的 VS Code 扩展支持新语法高亮。

安装包具有 VeraFlow 更新签名，尚无 Apple 公证和 Windows 发布者签名。请使用 `SHA256SUMS.txt` 核对下载文件。
