VeraFlow 核流 0.21.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Use JSON5 for source headers and strict JSON for exchanging records.
- Prepare several outputs from the same step, or use a step to collect and verify fields.
- Review incoming record changes and keep verification on unchanged values.
- Use custom form values with a reusable form. The session window can stay on top in either layout.
- Extract `VeraFlow_Demo.zip` and open `source/housing-demo.md` for a five-minute practice workflow with fictional data.
- Includes the VeraFlow VS Code extension. [English guide](https://github.com/iandorsey00/veraflow/blob/v0.21.0/README.md) · [简体中文指南](https://github.com/iandorsey00/veraflow/blob/v0.21.0/README.zh-CN.md)

Packages have VeraFlow updater signatures. Apple notarization and Windows publisher signing are pending. Verify downloads against `SHA256SUMS.txt`.
