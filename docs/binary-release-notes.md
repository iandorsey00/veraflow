VeraFlow 核流 0.25.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- The source-checkout CLI has 14 commands for form inspection, record validation and merging, evidence review, CSV, and output generation. Use `--help --json` for the command catalog and `--json-errors` for structured diagnostics. [English CLI guide](https://github.com/iandorsey00/veraflow/blob/v0.25.0/docs/cli.md) · [简体中文指南](https://github.com/iandorsey00/veraflow/blob/v0.25.0/docs/cli.zh-CN.md)
- The résumé template uses Helvetica, retains Chinese glyphs, and lets skills and projects follow the rest of the résumé without a forced page break.
- The release includes bilingual examples and the VS Code extension. PDF conversion uses Pandoc and XeLaTeX on macOS.

Packages have VeraFlow updater signatures. Apple notarization and Windows publisher signing are pending. Verify downloads against `SHA256SUMS.txt`.

### 简体中文

源码版命令行提供 14 条命令，可检查表单、校验及合并记录、审阅证据、读取 CSV 并生成输出。简历以 Helvetica 为主字体，保留中文显示，技能和项目按内容自然分页。发布包包含双语示例和 VS Code 扩展。macOS 上的 PDF 转换依赖 Pandoc 和 XeLaTeX。

安装包具有 VeraFlow 更新签名，尚无 Apple 公证和 Windows 发布者签名。请使用 `SHA256SUMS.txt` 核对下载文件。
