VeraFlow 核流 0.12.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Inline conditions accept placeholders, single quotes, and line breaks between clauses. Grouped sections can use a custom separator.
- Choices appear first in forms and can be selected directly in Scanner. Prepared output appears in Recent outputs. You can return to your filled form or Scanner when closing from output.
- The release includes `VeraFlow_VSCode.vsix`, and the app has new Simplified Chinese guides. [English guide](https://github.com/iandorsey00/veraflow/blob/v0.12.0/README.md) · [简体中文指南](https://github.com/iandorsey00/veraflow/blob/v0.12.0/README.zh-CN.md)

Packages have VeraFlow updater signatures. Apple notarization and Windows publisher signing are pending. Verify downloads using `SHA256SUMS.txt`.

### 简体中文

行内条件支持占位符、单引号和分行排版。合并区段时可设置分隔符。填写表单时优先显示选项，扫描器中可直接选择。准备好的结果会进入「最近的输出」。从输出关闭时可返回已填写的表单或扫描器。发布包提供 Windows x64、两种 macOS 架构和 VS Code 扩展。

安装包具有 VeraFlow 更新签名，尚无 Apple 公证和 Windows 发布者签名。请使用 `SHA256SUMS.txt` 核对下载文件。
