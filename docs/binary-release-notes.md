VeraFlow 核流 0.20.0 is a public preview for Windows x64, macOS Apple Silicon, and macOS Intel.

- Define **Steps** to collect fields and prepare outputs as information arrives. Earlier values and verification carry forward.
- Review affected outputs when you edit a previous step. VeraFlow flags sections that were already transferred.
- Add plain-text guidance to a named output. It appears in the preview and on the output screen.
- Includes the VeraFlow VS Code extension. [English guide](https://github.com/iandorsey00/veraflow/blob/v0.20.0/README.md) · [简体中文指南](https://github.com/iandorsey00/veraflow/blob/v0.20.0/README.zh-CN.md)

Packages have VeraFlow updater signatures. Apple notarization and Windows publisher signing are pending. Verify downloads using `SHA256SUMS.txt`.

### 简体中文

表单可分步骤填写，每步生成一个命名输出，已填写的值和核对状态可沿用。修改前面步骤的值后，应用会提醒你检查受影响的输出。还可为命名输出添加纯文本说明。

安装包具有 VeraFlow 更新签名，尚无 Apple 公证和 Windows 发布者签名。请使用 `SHA256SUMS.txt` 核对下载文件。
