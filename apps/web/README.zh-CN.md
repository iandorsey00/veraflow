# VeraFlow Web

[English](README.md)

将 VeraFlow 模板导出为一个可交互的 HTML 文件。用浏览器直接打开，填写一次，核对关键值，即可生成用于邮件、工单或日志的命名输出。导出的表单支持离线使用。

**来源 → 工作记录 → 命名输出 → 目标位置**

工作记录是表单维护的一组字段值。JSON 以稳定的字段 ID 将记录传给其他工具。可从 JSON 或 JSON5 记录开始，生成输出或填写可复用表单。如需空白表单，可打开 `.veraflow` 或 `.vf` 模板。独立 HTML 支持手动填写、审阅后导入记录，以及从带标签的文本或候选值 JSON 提取数据。有关各界面的输入及转换格式，请参阅[使用指南](docs/usage.zh-CN.md)和[演示示例](examples/README.zh-CN.md)。

选择“打开采集请求…”可将桌面端发出的采集请求导出为独立的离线 HTML 问卷。填写者可下载兼容的回答 JSON。[离线采集教程](docs/collection.zh-CN.md)

## 运行导出工具

使用 Node.js 22 或更高版本。

```sh
cd apps/web
npm ci
npm start
```

在浏览器中打开 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。结束时按 Control-C。已构建的发行包也可解压后通过静态 Web 服务器提供。

也可直接使用命令行导出。

```sh
npm run build
npm run export:html -- examples/service-case.veraflow dist/service-case.html
```

模板头支持 JSON 或 JSON5，使用桌面端解析器拒绝重复键及非有限数字。可用 `--timestamp` 为输出文件名添加 UTC 时间戳。省略目标路径时，HTML 保存在模板旁；已有同名文件时会报错。模板仍是可编辑的源文件。

## 导出并填写

- 在导出页面选择模板，再点击“下载 HTML 表单”。在“表单工具”中可添加文件名时间戳、记录源文件名或启用预填。默认只保留模板设定的默认值。勾选“包含预填回答”可使用模板中已保存的回答。如需审阅单独的记录，请选择“从数据开始 → 打开 JSON / JSON5…”，并在审阅界面选择“使用表单文件”。命令行选项为 `--include-responses`、`--responses record.json5` 和 `--include-source-name`。预填值可直接从 HTML 中读取。
- 导出页面和表单界面均支持英文和简体中文。模板中的标题、字段说明和输出文本保留原文。托管页面检测到有更新时会显示“更新应用…”。在已构建且干净的仓库中，从 `apps/web` 运行 `npm run export:html -- --update`，可快进到远端最新的稳定 `web-v` 标签并重新构建 Web。现有 HTML 表单需要重新导出才能使用新运行时。
- 在导出的表单中，字段上方的“待处理”显示当前步骤或所选输出的未填写和待核对数量。可跳转至下一项，也可使用各项链接。核对不一致时保留原值，编辑字段会清除核对状态。
- 点击“从来源提取…”可粘贴带标签的文本（包括从网页复制的可见文本）、读取剪贴板或载入一个 UTF-8 文本文件。审阅时先处理冲突、歧义和无效值，再看新增值。匹配项默认折叠。替换和有歧义的候选值需明确选择，应用后仍须单独核对。候选项及证据可另存为严格 JSON。若先提供原文，导入时会核对引文。
- 使用“生成输出”生成所选输出。多输出步骤也可一次生成全部。可分段复制、复制整项输出，或下载文本。“下载输出 JSON”保存已生成的输出及其命名段落。如果一次生成了本步骤的全部输出，则下载完整的一组输出。剪贴板受阻时可手动复制已选文本。复制与“下一步”是独立操作；回到上一步时仍保留后续填写的值。
- 在打开的表单中，使用“表单工具 → 打开 JSON / JSON5…”可比较当前值和传入值。值未变更的字段保留核对状态。发生变更的字段需要重新完成相应的核对。请参阅[派送演示](examples/README.zh-CN.md#从-json-生成派送输出)或[桌面端 CLI 与 Web 教程](docs/desktop-cli.zh-CN.md)。
- “表单工具 → 下载回答 JSON”保存全部或部分工作记录。未提供的键保留原值，`null` 清除原值，`""` 表示明确的空字符串。未填写也未预填的字段会省略，包括仅显示模板默认值的字段。在 VeraFlow Desktop 中打开同一模板，选择“表单工具 → 导入 JSON / JSON5…”，审阅并应用更改，然后按需核对。表单刷新或关闭时，在内存中的回答会清除。

导出的 HTML 内含样式、表单、定义和运行时，不会自动发起网络请求。页脚的 GitHub 链接可主动打开，表单详情可查看核心版本及可选的源文件名。邮件预览可能无法运行表单。受管理的设备可能限制本地 HTML、JavaScript、剪贴板或下载；如需部署，请咨询 IT 是否允许通过内部 HTTPS 提供同一文件。

## 发布与部署

Web 版本由[独立的包配置](package.json)定义。共享仓库中的 `web-vX.Y.Z` 标签会触发 Web 流程，生成 `veraflow-web-vX.Y.Z-static.zip` 和校验文件。桌面版继续使用 `vX.Y.Z` 标签。[原 Web 仓库的 0.5.0 发行包](https://github.com/iandorsey00/veraflow-web/releases/tag/v0.5.0)仍可使用。

部署时解压静态发行包，或构建 `apps/web` 后，将 `apps/web/dist/` 作为静态网站目录。请同时部署 `index.html`、带内容指纹的 JavaScript 和 CSS 以及 `version.json`。回退时重新部署上一版的完整静态目录。构建和发布压缩包不会自动更新线上网站。

## 开发

从 `apps/web` 运行 `npm test`，可检查导出、隐私、内容安全策略、命名输出和版本选择。还可在仓库根目录运行一次 `npm ci`，启用桌面 CLI 往返测试。用 `npm run test:browser` 运行 Chromium 测试；安装相应浏览器后，也可用 `VERAFLOW_BROWSER=edge` 或 `VERAFLOW_BROWSER=webkit`。

Web 直接使用[共享核心](../../src/core/)，并保留独立的依赖和版本。表单页脚显示 Web 版本，表单详情显示共享核心版本。构建 Web 后，也可从仓库根目录运行 `npm run export:html -- apps/web/examples/service-case.veraflow`。
